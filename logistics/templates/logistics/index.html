About this project

This project provides clean implementations of common data structures following PEP8 Python coding standards. It is designed as a learning resource for understanding the internal mechanics and properties of each structure.

The repository includes binary trees, search trees, expression trees, AVL trees, graphs, heaps, and a Tic-Tac-Toe exercise that uses a tree-based strategy.

Binary tree implementation

Features

  • BinaryNode: represents a node with data and child references.
  • BinaryTree: provides the base binary tree structure.
  • Property-based access: keeps getter and setter behavior clear.
  • PEP8 compliant: follows Python style guidelines.
node = BinaryNode(data=10)
node.left_child = BinaryNode(5)
node.right_child = BinaryNode(15)

tree = BinaryTree()
tree.root = node

Technologies and learning goals

Language: Python 3.x

Focus: object-oriented design, algorithms, PEP8 standards, properties, context managers, and type hints.

This is an educational project for understanding core data structures, writing maintainable code, and building strong algorithm fundamentals.
